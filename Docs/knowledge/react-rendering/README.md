# React rendering model

This repo teaches the **modern** React model by default: function components, hooks, concurrent rendering ideas, and (in Next.js) Server vs Client Components.

Pages follow the same **Dummy → CTO ladder** as [architecture styles](../architecture-styles/README.md): quick picture first, then when/when-not, working examples, rich seams/failures, and CTO notes where relevant.

| Page | Role |
|------|------|
| [modern-lifecycle.md](modern-lifecycle.md) | Default mental model |
| [legacy-class-lifecycle.md](legacy-class-lifecycle.md) | **Legacy / comparison only** |

Do not start new examples with class components unless the lesson is historical comparison.
